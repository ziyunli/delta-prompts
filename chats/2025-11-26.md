# delta-prompts Brainstorming Session

**Date:** 2025-11-26
**Participants:** Yun Sama, Claude

## Initial Idea

Yun Sama proposed creating a small webpage to show the differences between system prompts as companies release new LLMs. The primary focus is on Claude, using prompts from https://platform.claude.com/docs/en/release-notes/system-prompts. The page should highlight changes between versions and allow comparing any pair of versions. Future support for other LLMs is desired.

---

## Discussion

### Q1: Primary Use Case

**Question:** What is the primary use case for this tool?
- Personal use
- Public resource
- Research/documentation

**Answer:** Public resource, hosted on GitHub Pages.

---

### Q2: Data Storage Approach

**Question:** How should the data/prompts be stored and updated?
- Manual curation via PRs
- Build-time fetch via GitHub Actions
- Client-side fetch

**Answer:** Start with manual curation, leave flexibility for automated fetching in the future.

---

### Q3: Metadata Fields

**Question:** What metadata should be stored alongside each prompt?

**Answer:** Include:
- Version identifier
- Release date
- Model name/family
- Source URL
- Provider

Exclude:
- Notes/changelog summary
- Who added it / date added

---

### Q4: Diff Display

**Question:** How should the diff be displayed?

**Answer:**
- **Layout:** Side-by-side
- **Granularity:** Word-level highlighting

---

### Q5: Navigation UX

**Question:** How should users navigate and select versions to compare?

**Answer:**
- Dropdown selectors for version selection
- Flat list of all versions (not filtered by model)

---

### Q6: Tech Stack

**Question:** What tech stack/framework preference?

**Answer:** Requested recommendation.

**Recommendation:** Astro - perfect for content-heavy static sites with islands of interactivity. Zero JS by default, great data loading story, GitHub Pages friendly. Use jsdiff or similar for diff computation.

**Decision:** Accepted Astro recommendation.

---

### Q7: Visual Style

**Question:** What visual style/aesthetic?

**Answer:** Minimal and utilitarian. Focus on function over form.

---

### Q8: Data File Organization

**Question:** How should prompt data files be organized?

Options presented:
- A: Flat by provider (one file per provider)
- B: Nested by provider + model
- C: One file per version

**Answer:** Option C - One file per version. Makes PRs clean (add one file per new prompt).

---

### Q9: Shareable URLs

**Question:** Should comparisons have shareable URLs?

Options:
1. Single page, no URL state
2. Query params
3. Path-based routes

**Answer:** Option 2 - Query params (e.g., `?left=version1&right=version2`)

---

### Q10: Project Name

**Question:** What should the project be called?

**Answer:** `delta-prompts`

---

### Q11: Additional Pages

**Question:** Beyond the main comparison page, any additional pages needed?

**Suggestion:** Just the diff page with a brief header explaining what it is. README handles contribution guidelines.

**Answer:** Sounds good.

---

### Q12: Mobile Support

**Question:** Does it need to work well on mobile?

Options:
1. Desktop-first, mobile acceptable
2. Fully responsive
3. Desktop only

**Answer:** Option 3 - Desktop only for v1.

---

### Q13: Initial Data Set

**Question:** What prompts should seed the initial release?

Options:
1. Just Claude prompts from Anthropic docs
2. Claude + one other provider
3. Minimal proof of concept (2-3 versions)

**Answer:** Option 1 - All available Claude prompts.

---

### Q14: Default View

**Question:** What should the default view be when someone first lands on the page?

Options:
1. Latest vs previous
2. Empty state
3. Latest vs earliest

**Answer:** Option 1 - Latest vs previous (most useful default).

---

## Final Summary

| Aspect | Decision |
|--------|----------|
| Project Name | delta-prompts |
| Hosting | GitHub Pages |
| Data Storage | Manual curation (JSON files), one file per version |
| File Structure | Nested by provider: `/data/anthropic/*.json` |
| Metadata | Version ID, release date, model name, source URL, provider |
| Diff Display | Side-by-side, word-level highlighting |
| Navigation | Two dropdown selectors, flat list of versions |
| Default View | Latest vs previous version |
| URLs | Query params for shareable comparisons |
| Tech Stack | Astro + jsdiff |
| Visual Style | Minimal, utilitarian |
| Mobile | Desktop only (v1) |
| Initial Data | All available Claude prompts |
| Additional Pages | None (just main diff page with header) |
